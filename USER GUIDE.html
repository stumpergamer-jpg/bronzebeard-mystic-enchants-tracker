📜 Guide d'Utilisation - Mystic Enchants Tracker (v1.6)

Bienvenue sur le Mystic Enchants Tracker, l'outil ultime pour suivre votre progression dans la collecte des enchantements sur WoW Ascension.

🚀 Démarrage Rapide

Double-cliquez simplement sur le fichier index.html pour lancer l'application dans votre navigateur web. Aucune installation ni connexion internet n'est requise (sauf pour regarder les vidéos YouTube).

🛠️ Fonctionnalités Principales

1. Suivi de Progression ("Collect")

  • Collecter un sort : Cliquez sur le bouton "Collect" (ou le texte "✓ Collect") à gauche de chaque ligne. La ligne deviendra verte.
  • Retirer un sort : Cliquez sur le bouton "✕" pour annuler la collecte.
  • Barres de progression : Vos progrès sont calculés en tempo réel. Les titres sont dynamiques :
    • Global/Faction : Affiche "Progression Alliance" ou "Progression Horde" selon le filtre.
    • Classe : Affiche le nom et l'icône de la classe sélectionnée.
    • Région : Affiche le nom spécifique de la région sélectionnée.

2. Filtrage & Recherche

  • Search : Tapez le nom d'un sort ou d'une zone pour filtrer instantanément la liste.
  • Faction : Filtrez par LES DEUX, Alliance, ou Horde.
  • Class : Affichez uniquement les sorts d'une classe spécifique.
  • Region : Filtrez par zone géographique (ex: Orneval...).
  • Langue : Support complet de l'Anglais, Français, Espagnol, Allemand et Italien.

3. Guides & Localisations (Mis à jour v1.6)

La colonne de droite "Guide" vous aide à trouver les enchantements :

  • WATCH : Ouvre une vidéo YouTube montrant l'emplacement exact.
  • MAP : Ouvre une image de la carte (si disponible dans le dossier Nonvid Locations).
    Note : L'outil détecte automatiquement si une image est disponible.
  • UNKNOWN : Indique qu'aucune vidéo ni carte n'est connue pour le moment.

4. Sauvegarde & Données

  • 💾 Save : Exporte votre progression actuelle dans un fichier .json. Conseillé de le faire régulièrement !
  • 📂 Load : Charge un fichier .json précédemment sauvegardé.
  • ✓ Collect All : Marque TOUS les sorts affichés comme collectés.
  • ✗ Collect None : Réinitialise (décoche) TOUS les sorts affichés.

5. Signaler un Bug

Un bouton ⚠️ Report Bug permet d'ouvrir un formulaire. Il pré-remplit les informations selon vos filtres actuels.

6. Système d'Annulation (Undo)

L'icône ↩️ Défaire permet d'annuler vos dernières modifications (jusqu'à 20 actions).

📂 Gestion des Images (Pour utilisateurs avancés)

Si vous souhaitez ajouter vos propres cartes :

  1. Prenez une capture d'écran de l'emplacement.
  2. Nommez l'image exactement comme le sort, suivi de "Location". Exemple : Omen of Fatality Location.png. Si spécifique à une faction : Nom Sort Location Alliance.png.
  3. Placez l'image dans le dossier Nonvid Locations.
  4. L'application affichera automatiquement le bouton MAP au prochain rechargement !

Merci également à toute la Communauté Bronzebeard.

📜 User Guide - Mystic Enchants Tracker (v1.6)

Welcome to the Mystic Enchants Tracker, the ultimate tool to track your enchantment collection progress on WoW Ascension.

🚀 Quick Start

Simply double-click the index.html file to launch the application in your web browser. No installation or internet connection is required (except to watch YouTube videos).

🛠️ Main Features

1. Progress Tracking ("Collect")

  • Collect a spell: Click the "Collect" button on the left of each row. The row will turn green.
  • Remove a spell: Click the "✕" button to uncollect.
  • Progress Bars: Your progress is calculated in real-time. The labels are dynamic:
    • Global/Faction: Shows "Alliance Progress" or "Horde Progress" when a faction is selected.
    • Class: Displays the name and icon of the selected class.
    • Region: Displays the specific name of the selected region.

2. Filtering & Search

  • Search: Type a spell name or zone to filter the list instantly.
  • Faction: Filter by BOTH, Alliance, or Horde.
  • Class: Show only spells for a specific class.
  • Region: Filter by geographic zone (e.g., Ashenvale...).
  • Language: Support for English, French, Spanish, German, and Italian.

3. Guides & Locations (Updated v1.6)

The rightmost "Guide" column helps you find enchantments:

  • WATCH: Opens a YouTube video showing the exact location.
  • MAP: Opens a map image (if available in the Nonvid Locations folder).
    Note: The tool automatically detects if an image is available.
  • UNKNOWN: Indicates that no video or map is currently known.

4. Save & Data

  • 💾 Save: Exports your current progress to a .json file.
  • 📂 Load: Loads a previously saved .json file.
  • ✓ Collect All: Marks ALL displayed spells as collected.
  • ✗ Collect None: Resets (unchecks) ALL displayed spells.

5. Report a Bug

A ⚠️ Report Bug button allows you to open a form. It pre-fills information about your current selection.

6. Undo Feature

Click the ↩️ Undo button to revert your last check/uncheck action.

📂 Image Management (For Advanced Users)

To add your own maps:

  1. Take a screenshot.
  2. Name it like the spell + "Location" (e.g., SpellName Location.png).
  3. Place it in the Nonvid Locations folder.
  4. The MAP button will appear automatically upon reload!
